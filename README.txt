SUNNY CHAUDHARY — PERSONAL PORTFOLIO
=====================================

HOW TO VIEW
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or another modern browser.
3. No build tools or server are required.

PERSONALIZE YOUR PHOTO
1. Add your own portrait photo inside the assets folder.
2. Name it: profile-photo.jpg
3. Open index.html and find:
   assets/profile-photo-placeholder.svg
4. Replace that path with:
   assets/profile-photo.jpg

A vertical portrait (around 4:5 ratio) works best.

ADD YOUR SOCIAL LINKS
Open index.html and search for:
   LinkedIn profile — add your URL
   GitHub profile — add your URL
Replace the href="#" values with your actual LinkedIn and GitHub profile URLs.

EDIT CONTENT
All page text is in index.html. Colors, layout, and responsive styling are in styles.css.
Interactive navigation and scroll effects are in script.js.

NOTES
- The portfolio includes details provided in your resume and relevant project context.
- Hobby/interests are presented as technology and problem-solving interests based on your shared background; edit them if you want to add personal hobbies.
- The NEPSE recommendation system is labeled as an ongoing prototype.
- The fatigue detection work is presented as research/project exploration, not as a published paper.
- LinkedIn and GitHub URLs are placeholders because actual profile URLs were not provided.

COLOR THEME
-----------
The portfolio uses a restrained charcoal, white, and soft-grey palette with a subtle neutral accent. Typography has been enlarged for readability.
- Each project card includes a GitHub link that opens GitHub repository search for that project name. Replace each search URL in index.html with the exact repository URL once you publish or share the repositories.
